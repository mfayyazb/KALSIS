# کالسیس | KALSIS

لندینگ فارسی و راست‌به‌چپ کالسیس، برند محصولات پروتئینی خانگی؛ با طراحی ریسپانسیو، افکت وکسل تعاملی، گالری محصولات و آماده‌سازی سفارش برای ایتا. ساخته‌شده با HTML، CSS و JavaScript، بدون وابستگی خارجی.

## اجرا روی کامپیوتر

به Node.js نیاز دارید. سورس سایت در پوشهٔ `site` قرار دارد. برای اجرا از پوشهٔ اصلی:

```powershell
npm run dev
```

پیش‌نمایش روی `http://127.0.0.1:4173` باز می‌شود. نصب پکیج لازم نیست.

## تنظیم شماره و دامنه

شماره تلفن، نشانی ایتا و دامنه را در [site/dist/config.js](site/dist/config.js) وارد کنید. شماره و دامنه فعلاً خالی هستند؛ پس از تکمیل، لینک آن‌ها در صفحه ظاهر می‌شود.

راهنمای کامل ساختار و ویرایش سایت در [site/README.md](site/README.md) است.

## میزبانی رایگان روی Cloudflare Pages

نسخهٔ فعلی کاملاً استاتیک است. برای اجرای آن نیازی به خرید سرور یا اجرای Node.js روی هاست نیست؛ فقط فایل‌های `site/dist` منتشر می‌شوند.

۱. در Cloudflare وارد بخش **Workers & Pages** شوید و یک پروژهٔ **Pages** با اتصال به Git بسازید.
۲. مخزن `mfayyazb/KALSIS` را انتخاب کنید.
۳. تنظیمات زیر را وارد کنید:

| تنظیم | مقدار |
| --- | --- |
| Production branch | `main` |
| Framework preset | `None` |
| Root directory | ریشهٔ مخزن؛ خالی بماند |
| Build command | `exit 0` |
| Build output directory | `site/dist` |

۴. با **Save and Deploy** سایت منتشر می‌شود و یک زیردامنهٔ رایگان `pages.dev` می‌گیرد. این مخزن به‌تنهایی به معنای انتشار سایت نیست؛ اتصال Cloudflare باید یک‌بار انجام شود.
۵. برای دامنهٔ شخصی، از **Custom domains → Set up a domain** استفاده کنید و رکوردهای DNS یا nameserverهایی را که پنل اعلام می‌کند در پنل دامنه تنظیم کنید. برای دامنهٔ اصلی، Cloudflare طبق راهنمای خود مدیریت DNS آن را لازم می‌داند؛ زیردامنه می‌تواند با CNAME متصل شود.

میزبانی فایل‌های استاتیک در پلن رایگان است؛ خرید و تمدید دامنه جداگانه است. بعد از اتصال Git، تغییرات شاخهٔ `main` به‌طور خودکار منتشر می‌شوند.

منابع رسمی: [میزبانی HTML استاتیک](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/)، [اتصال دامنه](https://developers.cloudflare.com/pages/configuration/custom-domains/)، [هزینهٔ درخواست‌های استاتیک](https://developers.cloudflare.com/pages/functions/pricing/#static-asset-requests).

## امکانات فعلی

- صفحهٔ راست‌به‌چپ و واکنش‌گرا با فونت‌های محلی وزیرمتن و لاله‌زار
- معرفی و فیلتر ۱۰ محصول، عکس‌های اصلی برند و محصولات
- افکت وکسل با موس و لمس و پشتیبانی از کاهش حرکت
- انتخاب چند محصول و مقدار، آماده‌سازی و کپی متن سفارش برای هماهنگی در ایتا
- دربارهٔ ما، روش سفارش، پرسش‌های متداول و معرفی باشگاه مشتریان با وضعیت «به‌زودی»

فرم سفارش، پیام را خودکار ارسال نمی‌کند. ثبت‌نام باشگاه، دیتابیس و پرداخت آنلاین هنوز پیاده‌سازی نشده‌اند.

## مجوز دارایی‌ها

فونت‌های وزیرمتن و لاله‌زار با مجوز SIL OFL عرضه شده‌اند؛ متن مجوزها در `site/dist/assets` موجود است. تصاویر و نشان کالسیس متعلق به صاحب برند هستند؛ عمومی بودن مخزن به معنای مجوز بازاستفاده از آن‌ها نیست.
