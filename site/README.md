# کالسیس — لندینگ فارسی

صفحهٔ تک‌صفحه‌ای و راست‌به‌چپ با عکس‌های اصلی محصولات، فونت‌های محلی وزیرمتن و لاله‌زار، دسته‌بندی ۱۰ محصول، افکت وکسل روی تصویر اصلی، حرکت هنگام اسکرول، فرم آماده‌سازی سفارش و پرسش‌های متداول.

## اجرا

به Node.js نیاز دارد؛ هیچ پکیج خارجی لازم نیست.

```powershell
cd D:\projects\kalsis\site
npm run dev
```

آدرس پیش‌نمایش: http://127.0.0.1:4173

فایل‌های داخل `dist` مستقیماً قابل میزبانی روی هر هاست استاتیک هستند و نیاز به build ندارند. `dist` پوشهٔ سورس سایت است؛ آن را حذف نکنید.

## تغییر شماره و آدرس‌ها

فایل `dist/config.js` را ویرایش کنید:

```js
window.KALSIS_CONFIG = Object.freeze({
  phone: '+989123456789',
  phoneDisplay: '۰۹۱۲ ۳۴۵ ۶۷۸۹',
  eitaa: 'https://eitaa.com/kalsis_1404',
  website: 'https://YOUR-DOMAIN.ir',
  city: 'یزد',
});
```

شماره و دامنه عمداً خالی گذاشته شده‌اند. تا زمان تکمیل، لینک آن‌ها در سایت نمایش داده نمی‌شود. لینک ایتا در تمام بخش‌ها از همین تنظیمات خوانده می‌شود. نشانی نمونهٔ بالا را با نشانی واقعی خودتان جایگزین کنید.

## ویرایش محتوا

- متن‌ها و بخش‌ها: `dist/index.html`
- محصولات، نام عکس‌ها و منطق سفارش: آرایهٔ `products` در `dist/app.js`
- رنگ‌ها و اندازه‌ها: `dist/styles.css` و متغیرهای ابتدای فایل
- عکس‌های اصلی و فونت‌ها: `dist/assets`

تصاویر عمومی خانوادهٔ محصولات در کارت‌ها مشخص شده‌اند. برای ناگت، تصویر ساختگی استفاده نشده است. بعد از دریافت عکس اختصاصی هر محصول، مسیر `image` آن را در آرایهٔ محصولات تغییر دهید.

## وضعیت امکانات

- فرم سفارش، متن قابل کپی می‌سازد. سفارشی روی سرور ذخیره یا خودکار ارسال نمی‌شود؛ مشتری باید از راه ارتباطی معرفی‌شده در کانال ایتا هماهنگ کند.
- باشگاه مشتریان در وضعیت «به‌زودی» است. عضویت، امتیاز، پیامک و دیتابیس هنوز وجود ندارند.
- قیمت، محدودهٔ ارسال و تاریخ مصرف اختراع نشده‌اند؛ هماهنگی این اطلاعات در ایتا انجام می‌شود.
- هیچ کوکی، سرویس تحلیل یا ذخیره‌سازی شمارهٔ مشتری وجود ندارد.
- افکت وکسل با موس و لمس کار می‌کند. با تنظیم کاهش حرکت سیستم خاموش می‌شود و بیرون از دید، پردازش آن متوقف می‌شود.
- فونت‌ها تحت مجوز SIL OFL هستند؛ متن مجوزها کنار فایل فونت‌ها قرار دارد.

## بررسی

```powershell
npm run check
```

نمایش سایت و فرم سفارش با مرورگر در اندازهٔ دسکتاپ و موبایل قابل بررسی است.
